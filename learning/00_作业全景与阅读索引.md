# Day31作业全景与阅读索引

## 现在必须知道的三件事

1. `interrupt`是主动暂停，不是报错。
2. `Command(resume=答案)`使用相同`thread_id`恢复原流程。
3. 产品风险和金额先由普通Python规则判断，人工再审核结果。

## 阅读顺序

1. `bank_day31/data.py`：先认清输入数据。
2. `recommendation_rules.py`：理解风险和金额双条件。
3. `tests/test_full_bank_hitl.py`：把测试当需求合同。
4. `full_bank_hitl.py`中的`FullBankState`。
5. 依次阅读画像、推荐、复核、确认、执行五个节点。
6. 阅读`create_graph`中的节点和边。
7. 阅读`start_flow`和`resume_flow`。
8. 最后阅读`run_evidence.py`。

不要从第一行到最后一行硬读完整文件，也暂时不要阅读LangGraph第三方源码。

## 黄金执行路径

```text
start_flow
→ graph.invoke(initial_state, thread_config)
→ profile_analysis
→ initial_recommendation
→ human_review中的interrupt
→ resume_flow和Command(resume)
→ customer_confirmation中的interrupt
→ resume_flow
→ execute_operation
→ END
```

## 学习停止标准

当你能够解释入口、五个节点、两次中断、一个恢复方法和三个结束分支时，本轮阅读完成；不以“读完所有文件”为标准。
